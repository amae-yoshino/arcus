# 導入・更新・削除

## 導入

1. .NET 10 Windows Desktop Runtime x64をMicrosoftの公式配布元から導入します。
2. GitHub Releasesのベータ版ZIPを選び、任意の書き込み可能なフォルダに展開します。ソースコードのZIPとは異なります。
3. arcus.exeを起動します。通常は管理者として実行する必要はありません。
4. タスクトレイのアイコンから設定を開きます。取得するファイルマネージャー、お気に入り、表示言語を選び保存します。
5. 対応アプリの標準ファイルダイアログを開き、バーのフォルダをクリックします。

表示言語は `Windows (Auto)`、`日本語`、`English` から選べます。AutoはWindows UI言語が日本語なら日本語、それ以外なら英語です。保存するとトレイメニュー・フォルダバーに反映します。設定を再度開くと新しい言語で表示します。Windows共通ダイアログのボタン名はOSの言語に従います。

## 設定・自動起動

設定は `%AppData%\arcus\settings.json`、バックアップは `settings.json.bak` に保存します。お気に入りは同じ設定に含まれ、JSONで個別に入出力できます。設定ファイルを他人と共有するとパス情報が漏れるため注意してください。

自動起動は設定で有効にして保存した場合、現在ユーザーのRunレジストリのarcus値に実行ファイルの場所を登録します。全ユーザーやサービスには登録しません。

## 更新

1. 現在の設定フォルダを必要に応じてバックアップします。
2. トレイメニューからarcusを終了します。
3. 新しい配布ZIPを展開してarcus.exeを起動します。AppDataの設定は引き継ぎます。
4. exeの保存場所が変わり、自動起動を利用している場合は設定を保存し直してください。
5. 既に開いているダイアログは開き直し、新しいフォルダ一覧を取得します。

ベータ版間や旧版への戻しでは設定の完全な互換性は保証しません。未知の設定項目は無視され、保存し直すと失われる場合があります。

## 削除

自動起動を無効にして保存→トレイから終了→展開したアプリのフォルダを削除します。設定・ログも削除したい場合だけ `%AppData%\arcus` を別途削除してください。

## 困ったとき

- 起動しない: Desktop Runtime x64か、ZIPを展開済みか確認します。
- バーが出ない: 有効設定、除外アプリ、標準ダイアログか、権限差がないか確認します。
- フォルダが古い: ダイアログを開き直します。Files・OneCommanderの保存タブ情報は即時更新されない場合があります。
- 移動を確認できない: ダイアログの実際の場所とアドレス欄を確認してから続行してください。自動で保存や開くの確定は行いません。

不具合報告時はベータ版番号と再現手順を添え、パス・ファイル名・ユーザー名等を伏せてください。
